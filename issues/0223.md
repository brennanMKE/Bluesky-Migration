# 0223 — Immersive video feed never removes its end-of-playback observer (leak)

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskyFeed |
| **Platform** | iOS |
| **First seen** | 2026-06-11 |

## Description

Swiping through the video feed registers a `.AVPlayerItemDidPlayToEndTime` observer per page that is never torn down; observers/closures accumulate, leaking memory and potentially firing seek/play against stale items.

## Evidence

`VideoFeedView.swift` `setUpPlayer()` (~404-412) registers via block-based `addObserver(forName:object:queue:)` and discards the returned token. `tearDownPlayer()` (~438-444) calls `removeObserver(self as Any, …)`, but the block API registers an internal token object, not `self` (a View value type), so the removal is a no-op. The only stored token is the unrelated periodic-time observer.

## Suggested fix

Capture the token from `addObserver(forName:…)` into state and `removeObserver(token)` in teardown; drop the ineffective `removeObserver(self as Any, …)`.
