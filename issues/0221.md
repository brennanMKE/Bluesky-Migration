# 0221 — Group system-message actors not resolved via `relatedProfiles`; removed/left users show a raw DID

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskyMessages |
| **Platform** | All |
| **First seen** | 2026-06-11 |

## Description

System events referencing a user who is no longer a convo member render a truncated raw DID instead of @handle — exactly the common case ('X removed Y', 'Y left the group').

## Evidence

`MessageThreadScreen.swift:411-413` resolves senders only from the member list; `actorLabel` (422-431) falls back to `String(raw.prefix(12))+"…"`. Same in ConversationListScreen.swift:291-296. `relatedProfiles` ([DID: ProfileBasic]) is mentioned only in a comment (Chat.swift:266) and never decoded/consulted.

## Suggested fix

Decode the `relatedProfiles` map from getConvo/getMessages and consult it (in addition to `members`) in sender/actor resolution.
