# 0230 — SavedFeeds `.task` reload silently discards unsaved pin/reorder/delete edits

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskyFeed |
| **Platform** | All |
| **First seen** | 2026-06-11 |

## Description

If the My Feeds screen's `.task` runs again (view re-appears) after the user pinned/reordered/deleted but before tapping Save, `load()` overwrites `feeds` from the server, discarding the edits while `hasChanges` stays true — Save then persists the un-edited list.

## Evidence

SavedFeedsScreen.swift:80 `.task { await viewModel.load() }`; `SavedFeedsStore.load()` unconditionally `feeds = prefs.savedFeeds` (line 55). Local mutations live in the same `store.feeds`, so reload clobbers them; no `hasChanges` guard.

## Suggested fix

Guard the reload (only on first appearance / when `!hasChanges`), or merge pending edits into the freshly loaded list instead of replacing.
