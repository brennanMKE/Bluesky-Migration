## Description

The home feed (`FeedView` / `FeedStore`) is the first screen a user sees and the highest-traffic path in the app. Feed rendering bugs have shipped repeatedly — broken dark mode (#0003), duplicate view models (#0049), stale cache (#0048), action buttons producing no state change (#0041, #0053). None were caught by automated tests. This suite locks in feed loading, post-cell rendering, and interaction button presence so regressions surface on the first CI run that breaks them.

Depends on #0175 (foundation).

## Regressions this suite would have caught

- **#0003** — Feed list ignored dark mode. A test asserting the feed background color matches the expected theme value would have caught it.
- **#0041 / #0053** — Like state stale after tap; like state doesn't persist. A test tapping the like button and asserting the button's accessibility value flips would catch the local-state regression. Persistence requires a relaunch cycle.
- **#0048** — Feed cache not used when offline. A test launching offline (block network via `XCUIApplication.launchEnvironment`) and asserting cached posts are visible would have caught it.
- **#0049** — `FeedView` task fired twice, creating duplicate view models. A test asserting post count is not doubled after a tab switch would have caught the duplication.

## Test cases

All tests use the #0175 harness. `launch(script: [.selectTab(.home), .waitForFeedLoad(minPosts: 1)])`.

### Feed loads and renders posts

- **At least one post cell is visible after launch.** Assert `app.cells["post-cell"].firstMatch.exists`.
- **Post cell contains expected elements.** Assert the first cell contains an avatar, display name, handle, post text, and action row (`post-action-like`, `post-action-repost`, `post-action-reply`, `post-action-share`).
- **No duplicate cells.** Assert `app.cells["post-cell"].count` is the same before and after switching away to Search and back to Home.

### Post interactions

- **Like button tap changes accessibility value.** Tap `post-action-like`. Assert its `accessibilityValue` (e.g. `"liked"` vs `"not liked"`) changes within 1 s.
- **Reply button navigates to composer or thread.** Tap `post-action-reply` on first post. Assert either a sheet appears or `ThreadView` pushes (`thread-view` accessibility identifier exists).

### Screenshot

- `screenshot(screen: "home-feed")` — captured after `waitForFeedLoad`.
- `screenshot(screen: "home-feed-dark")` — repeat with dark mode launch argument.

## Notes

- Accessibility identifiers (`post-cell`, `post-action-like`, etc.) need to be added to `PostCardView` and its action row as part of implementing this suite — the identifiers are the coupling surface between tests and views.
- Feed loading requires a live network connection. Mark tests that need the network with a custom tag so they can be excluded from offline CI runs.
- Like persistence across relaunch is a separate concern from local state flip; test them separately.
