# 0229 — Quote-with-media posts aren't filtered when the quoted record is detached

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskyFeed |
| **Platform** | All |
| **First seen** | 2026-06-11 |

## Description

On the Quotes screen, a quote post embedding both media and a detached quoted record still renders, showing an empty/broken quote block (RN strips these).

## Evidence

`QuotesOfScreen.filterDetached(_:)` only inspects `.record`: `guard case .record(let recordEmbed) = post.embed else { return true }`. A quote-with-media decodes to `EmbedView.recordWithMedia(record:media:)` (Embed.swift ~369), which the guard rejects and keeps, so the `viewDetached` check never runs.

## Suggested fix

Also handle `.recordWithMedia(let recordEmbed, _)` in `filterDetached`, applying the same `viewDetached` check to `recordEmbed.record`.
