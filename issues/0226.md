# 0226 — List report dialog never offers/uses a labeler proxy (always posts to PDS default)

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskyLists |
| **Platform** | All |
| **First seen** | 2026-06-11 |

## Description

Reporting a list always sends the report to the PDS default with no `atproto-proxy` labeler header, even when the user subscribes to labelers handling record reports; the labeler chooser never appears for list reports.

## Evidence

`ListDetailScreen` (ListDetailScreen.swift:102-116) uses the 2-arg `ReportDialog(subject:onSubmit:onDismiss:)` which defaults `availableLabelers: []` (ReportDialog.swift:282-292). With an empty set, `candidateLabelers` is always empty (564-597) so `submit()` passes `labelerDID == nil` (630-642) and posts with no `proxyDID`. The labeler-aware initializer exists but is never given the subscribed labelers `ModerationStore.loadSubscribedLabelers()` already resolves.

## Suggested fix

Resolve subscribed labelers and pass them as `availableLabelers` to the labeler-aware initializer, forwarding the chosen `labelerDID` into `network.post(..., proxyDID:)`.
