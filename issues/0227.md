# 0227 — Search Feeds tab has no pagination and discards the cursor

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskySearch |
| **Platform** | All |
| **First seen** | 2026-06-11 |

## Description

Feed search results are capped at the first page; scrolling to the bottom never loads more, unlike People and Posts tabs.

## Evidence

People/Posts lists attach last-row `onAppear { loadMore() }` (SearchScreen.swift:201-205, 232-236) but `feedResults` (249-265) does not. The store's feeds case never reads/stores a cursor and overwrites `suggestedFeeds` (SearchStore.swift:97-99); there is no `feedsCursor` field (only actors/posts cursors).

## Suggested fix

Add a feeds cursor, append on `fresh:false`, and add the last-row loadMore trigger to `feedResults` (combine with the endpoint fix in #0211).
