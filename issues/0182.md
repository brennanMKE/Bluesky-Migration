## Description

The composer sheet (`ComposerSheet`) has stale-state bugs (#0151 — opens with stale pre-filled text), and the full feature set (video picker, link card preview, thread composer, draft persistence) is in-progress (#0034). A UI test suite asserts the composer opens cleanly with an empty text field, character count is correct, the Post button enables only when text is non-empty, and cancellation closes without posting.

Depends on #0175 (foundation).

## Regressions this suite would have caught

- **#0151** — Composer opened with stale text pre-filled when no draft was resumed. A test asserting `composer-text-field` is empty on fresh open would have caught it immediately.
- **#0034 (in-progress)** — As each composer feature lands (link card, thread mode, draft persistence), the corresponding test case locks it in. Starting the suite now means the baseline is already green when new features are added.

## Test cases

All tests use the #0175 harness. `launch(script: [.selectTab(.home), .openComposer])`.

### Composer opens clean

- **Composer sheet appears.** Assert `composer-sheet` exists within 2 s.
- **Text field is empty on fresh open.** Assert `composer-text-field.value == ""`.
- **Character count starts at 0.** Assert `composer-char-count` label shows `"0 / 300"` (or equivalent format).

### Text input and Post button state

- **Post button disabled when text field empty.** Assert `composer-post-button.isEnabled == false` initially.
- **Post button enables after typing.** Type "Hello" into `composer-text-field`. Assert `composer-post-button.isEnabled == true`.
- **Character count updates.** After typing 5 characters, assert count label shows `"5 / 300"`.
- **Approaching limit shows warning.** Type 280+ characters. Assert `composer-char-count` label is non-green (color is not assertable via XCUITest; assert the count value is ≥ 280 and ≤ 300).

### Cancel closes without posting

- **Cancel dismisses the sheet without navigating.** Tap `composer-cancel-button`. Assert `composer-sheet` no longer exists. Assert feed is still visible and unchanged.

### Screenshot

- `screenshot(screen: "composer-empty")` — before typing.
- `screenshot(screen: "composer-with-text")` — after typing a short post.

## Notes

- Do not actually submit a post during testing against the production `bsky.social` PDS — a `.test` domain or local PDS is required, or tests should be tagged `@network-write` and excluded from default CI runs.
- The `openComposer` intent sets `MainTabView.showComposer = true` via `UITestNavigator`. The composer sheet is presented via `.sheet(isPresented: $showComposer)` in `MainTabView`, so the intent fires correctly from any tab.
