# 0211 — Search Feeds tab uses the wrong endpoint and param, ignoring the query

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskySearch |
| **Platform** | All |
| **First seen** | 2026-06-11 |

## Description

On Search → Feeds, results are identical regardless of what's typed — it shows generic curated suggestions, not feeds matching the query.

## Evidence

`SearchStore.search` feeds case (SearchStore.swift ~97-99) calls `lexicon: "app.bsky.feed.getSuggestedFeeds"` with `["q": q]`. That endpoint is curated suggestions and ignores a search term. The codebase does feed *search* via `app.bsky.unspecced.getPopularFeedGenerators` with param key `query` (BlueskyFeed/SuggestedFeedsStore.swift:102, BlueskyLists/StarterPackWizardSearchStore.swift:127). Both the lexicon and the param key are wrong here. Confirmed firsthand.

## Suggested fix

Use `lexicon: "app.bsky.unspecced.getPopularFeedGenerators"` with `params: ["query": q, "limit": "25"]`, matching the existing `SuggestedFeedsStore` usage.
