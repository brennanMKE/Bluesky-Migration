# 0231 — Report dialog allows submitting details past the displayed 300-character limit

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskyModeration |
| **Platform** | All |
| **First seen** | 2026-06-11 |

## Description

The 'Additional details' editor shows an '<n> / 300' counter that turns red past 300, implying a hard cap, but Submit stays enabled and sends the over-length string; the server rejects it with a generic error.

## Evidence

Counter/red styling at ReportDialog.swift:395-397. `canSubmit` (606-612) and `submit()` (630-647) never check `details.count`; `reason` is sent verbatim after trimming.

## Suggested fix

Add `details.count <= 300` to `canSubmit` (or truncate / disable past the cap).
