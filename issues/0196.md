## Description

The Mac app's top bar accumulates multiple buttons on the right side — refresh (`arrow.clockwise`), compose (`square.and.pencil`), and Feeds (`#`). Per the RN reference layout, only the `#` button belongs there. A working reference implementation exists in the prototype at `~/Developer/Bluesky/MacBlueskyNav` (`HomeFeedView.swift` — single `.primaryAction` ToolbarItem with the `number` glyph).

## Steps to reproduce

1. Launch the Mac app and sign in.
2. Look at the right side of the window toolbar on the Home tab.

## Expected behavior

Only the Feeds (`#`) button appears at the trailing edge of the top bar, as in the RN iPhone app and the prototype.

## Actual behavior

User report: "the top bar has multiple buttons crammed on the right side when only the # button should be there." The unified macOS window toolbar collects the sidebar column's refresh button (`MainTabView.swift` ~line 317) plus the detail column's compose (~line 877) and `#` (~line 905) items, all trailing.

## Notes

- Compose moves to a floating bottom-right button — that is [#0197](0197.md); this issue covers removing it (and the refresh button) from the toolbar.
- The leading edge changes from the system sidebar toggle to a hamburger menu — that is [#0198](0198.md).
