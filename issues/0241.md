## Description

Create a website for releasing the Mac app, working like `~/Developer/brennanMKE/Batty`: a static site that hosts the download (DMG), the Sparkle `appcast.xml` that drives automatic updates, and a changelog — plus a deploy script so publishing a release is one command.

## Expected behavior

A `website/` directory in the app repo, modeled on Batty's (`index.html`, `changelog.html`, `privacy.html`, `appcast.xml`, `downloads/`, css/assets), deployed to a stable HTTPS domain. Each release: copy the DMG into `downloads/`, prepend the `<item>` generated by `appcast-item.sh` (#0191) to `appcast.xml`, stamp the changelog, run `deploy-website.sh`. Installed apps then see the update via Sparkle (#0190).

## Actual behavior

No website, no hosting, no appcast.

## Notes

- **Model:** Batty's `website/` (index, changelog, privacy, demo page, `downloads/`, `appcast.xml`) and its `scripts/deploy-website.sh` (rsync to host). Batty serves from `batty.sstools.co`; an analogous subdomain on `sstools.co` is the natural choice here — **domain/site name needs a decision**, including how the site presents an unofficial Bluesky client (naming/trademark consideration).
- **Appcast discipline:** the feed URL must match `SU_FEED_URL` baked into the app (#0190), and items are only ever generated from the built DMG by `appcast-item.sh` — hand-editing version attributes is the "you're up to date on an old version" failure mode. Keep the skeleton from the `mac-release` skill's `templates/appcast.xml` (one annotated `<item>`).
- **Hosting options** per the skill's `references/website-deploy.md`: self-host/rsync (Batty's approach), GitHub Pages, or S3 — pick based on where `sstools.co` DNS already points. HTTPS is required (Sparkle + ATS).
- **Beta channel:** if Beta and Prod get separate feeds (decision tracked in #0190), the site needs a second appcast (e.g. `appcast-beta.xml`) and the deploy script should publish both.
- **Publishing is outward-facing:** per the skill's safety rule, actual deploys are run by the user, not autonomously.
