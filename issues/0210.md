# 0210 — Editing display name/bio wipes the user's avatar, banner, pinned post, and self-labels

| | |
|---|---|
| **Status** | open |
| **Module** | BlueskyProfile |
| **Platform** | All |
| **First seen** | 2026-06-11 |

## Description

Saving the Edit Profile sheet (changing only name or bio) destroys the account's avatar, banner, pinned post, and any self-applied labels (e.g. the `!no-unauthenticated` PWI opt-out). After one edit the profile shows a blank avatar/banner.

## Evidence

`ProfileStore.updateProfile` (ProfileStore.swift ~609-621) blind-`putRecord`s `ProfileRecord(displayName:description:)`. `putRecord` REPLACES the whole `app.bsky.actor.profile` record, and `ProfileRecord` (BlueskyCore/Feed.swift ~305) carries only displayName/description/labels — no avatar/banner/pinnedPost. No `getRecord` is read first, so those fields are silently dropped. Confirmed firsthand.

## Suggested fix

Before `putRecord`, `getRecord` the current profile and merge new name/description into the existing record so avatar, banner, pinnedPost, and labels survive — or carry those blob refs through explicitly.
