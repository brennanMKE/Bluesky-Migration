# 0197 — macOS: post button should be a floating button at the bottom right, as in the RN app

| | |
|---|---|
| **Status** | open |
| **Module** | Bluesky-SwiftUI |
| **Platform** | macOS |
| **First seen** | 2026-06-11 |

## Description

On macOS the post composer is opened from a toolbar button. It should instead be a floating circular button at the bottom-right of the feed, matching the RN iPhone app. The iPhone build already does this (the iOS-compact FAB owns composition per `MainTabView.swift` ~line 851); macOS needs the same treatment. Reference implementation in the prototype at `~/Developer/Bluesky/MacBlueskyNav` (`HomeFeedView.swift` ~lines 63–78).

## Steps to reproduce

1. Launch the Mac app and sign in.
2. Look for the compose affordance on the Home tab.

## Expected behavior

A floating circular `square.and.pencil` button (56×56, accent background, shadow) anchored bottom-trailing over the feed opens the composer — as in the RN app and the prototype.

## Actual behavior

Compose lives in the window toolbar (`MainTabView.swift` ~line 877, `ToolbarItem(id: "bsky.compose", placement: .primaryAction)`), contributing to the crowded trailing toolbar ([#0196](0196.md)).

## Notes

- Prototype details worth mirroring: `ZStack(alignment: .bottomTrailing)` over the feed list, `.buttonStyle(.plain)`, 20pt trailing/bottom padding. The prototype also stages a bottom-left "new posts" button in the same ZStack — out of scope here, but keep the layout compatible.
- The existing iOS-compact FAB may be reusable; consider extracting it rather than writing a second one.
- **Do not copy screenshots from the prototype project — they are private images.** Reference its source only.
